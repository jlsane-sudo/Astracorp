# Cambio: costes progresivos de sede

## Objetivo

La sede corporativa era demasiado barata para el valor permanente que entrega. Este cambio endurece la progresion para que mejorar caracteristicas de HQ sea una decision estrategica y no una compra automatica temprana.

## Nuevo coste

Las mejoras de sede ahora usan un coste compuesto:

- creditos con curva mas agresiva por nivel;
- productos a partir de niveles superiores;
- recursos distintos segun el tipo de mejora;
- recursos avanzados en los ultimos niveles.

## Ejemplos de recursos por rama

- Centro logistico: mineral, componentes metalicos, marcos de aleacion, modulos de habitat.
- Departamento comercial: agua, energia, componentes metalicos, modulos de habitat.
- Sala de operaciones: celdas de energia, componentes, aleacion y oxigeno.
- Oficina defensiva: mineral, componentes, aleacion y oxigeno.
- Sala tactica: mineral, componentes, aleacion y modulos de habitat.

## Interfaz

La vista de sede ahora muestra:

- coste en creditos;
- productos requeridos;
- productos faltantes con el stock actual entre parentesis;
- bloqueo de compra si faltan creditos o recursos.

## Resultado de juego

La sede pasa a depender de la economia real del jugador. Para subir niveles altos ya no basta con acumular creditos: hace falta sostener cadenas productivas y usar el mercado/territorios para conseguir materiales.
